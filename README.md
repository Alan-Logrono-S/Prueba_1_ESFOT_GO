🚀 Descripción del Proyecto

ESFOT GO es un sistema web informativo orientado a la comunidad politécnica. Su objetivo es facilitar la localización de aulas, laboratorios y espacios académicos mediante una interfaz moderna, responsiva y dinámica.

El proyecto integra el consumo de APIs públicas y privadas, desplegado con tecnologías actuales del ecosistema frontend, todo dentro de un flujo de trabajo basado en Scrum.
